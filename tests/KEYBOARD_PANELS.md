# TypeX 键盘覆盖面板

入口：设置 → TypeX → 滑动面板。顶部与底部工具栏共享左、右和通用配置。
顶部／底部长滑开关位于设置 → TypeX → 手势设置 → 键盘工具栏手势，沿用原配置；此页也可进入各工具栏配置按钮手势。
左长滑打开左面板，右长滑打开右面板；通用配置由 Dock 上划或通用通知入口打开。三个面板各自配置内容和外观。

## 实现与边界

- `DXToolbarHorizontalGesture` 在 8pt 横向移动时认领拖动，松手时只分类一次。
- 长滑位移至少为 max(100pt, 工具栏宽度 × 30%, 起始按钮宽度 × 125%)，且横向位移至少是纵向的 1.5 倍。
- 全程留在起始按钮内的滑动执行该按钮动作；跨出按钮但不够长的拖动取消。
- 点击、长按和上下滑绑定保留；横向翻页、空格键翻页 Hook 和自动分页恢复全部移除。
- 顶部启用容量为配置列数 × 当前行数（1 或 2）；底部为 8。旧超量按钮保留记录并关闭。
- 面板直接挂到已存在的远程/系统键盘窗口，排在内容兄弟视图之上；不创建、切 key、隐藏或改系统窗口控制器。通知框、可见工具栏及键盘祖先视图框共同计算覆盖范围；键盘外区域不拦截触摸。优先系统键盘窗口，其次 activeInstance 的 window 和 TextEffectsWindow；没有键盘宿主时取消显示。
- 背景保留不透明底层，避免 SpringBoard 的远程键盘未被模糊采样时按键透出。窗口 API、命中测试和渲染仍需在设备验收。
- 面板本身不 resignFirstResponder，也不恢复键盘。动作沿既有路径执行：例如配置了“截图前隐藏键盘”的截图动作仍会隐藏键盘。
- 内容为圆形图标网格，可增删、排序、换动作、改名称图标；列数 3–5，内容大小 70–120%，深浅背景可选。
- 左/右/通用内容配置列表默认允许左滑显示“删除”。删除只保存当前面板的引用并立即刷新预览，不删除自定义动作定义或其他面板的引用。不设“编辑”模式，长按条目直接拖动排序，拖完即时保存；失效的滑动回调不能删除另一行。
- 面板添加/替换的“选择动作”页也可左滑删除自定义动作定义，复用原清理流程删除工具栏、子动作和三套面板引用，并清除当前勾选。不显示排序控件、不进入编辑模式；“添加”和批量“完成”保持可用。按稳定 selector 定位被删除项，旧滑动回调不能删除移动后的另一项。返回/完成时重读当前面板配置，避免把刚清理的引用写回。
- 每个面板顶部默认显示勿扰模式、无线网络、铃声静音、蓝牙、方向锁定及亮度/媒体音量滑条，使用控制中心样式。下面的动作网格完全由用户配置；未配置/删空时为空。顶部控件和网格共用纵向滚动面，低高度键盘也可访问全部内容。
- 面板仅引用有效的自定义动作，添加/替换选择器不展示基础动作；导入的基础动作或已删自定义动作不显示、不执行。原自定义 URL、App、文本、脚本协议继续沿用，新增自定义系统动作详见 SYSTEM_ACTIONS.md。
- 左右/通用配置互不覆盖。空配置保持空；配置缺失/格式无效时不添加任何动作。
- 键盘隐藏、宿主退后台、Scene 失活、旋转、偏好刷新、工具栏移出窗口时清理面板。
- 点击动作先同步关闭面板，再执行；没有延迟插入输入框的动画回调。执行前校验来源窗口、输入对象、Scene 与动作能力。
- 设置首页的条目由 Root.strings 翻译，面板入口和标题为“滑动面板”；列数和大小使用有中文标题的控件。
- 面板设置页提供左/右/通用预览，内容页提供当前面板预览；增删、排序、名称图标、列数、大小、深浅色修改后刷新。预览和真实面板共用 DXKeyboardPanelLayout.h 布局公式，预览图标不执行动作；顶部系统状态为示意，与实际面板共用控件。
- 首页下拉显示“搜索设置”，按名称和说明过滤首页条目并保留相关分组，清空恢复完整列表。面板设置页下拉显示键盘测试输入框；点击输入框弹出系统键盘，可从实际工具栏测试长滑面板。离开页面结束本页编辑。

## 自动验证

执行 `python3 tests/run-gesture-actions.py`，测试实际生产的手势分类、容量归一化、配置隔离、删除引用，生产键盘覆盖几何（含缺失通知、关闭单个工具栏及无效矩形），以及使用 UIKit 替身的生产 recognizer 状态机。
执行 `python3 tests/run-text-actions.py` 验证既有文本动作执行。
执行 `python3 tests/run-system-actions.py` 验证仅自定义动作过滤和键盘宿主优先级。
执行 `python3 tests/run-panel-controls.py` 验证固定控制白名单、状态编码、共享顶部布局、滑条请求合并、过期/超时和关闭取消；实际客户端入口测试使用真实 notify 状态槽和执行器替身。
执行 `python3 tests/run-settings-ui.py` 验证中文/宽度不敏感搜索、分组与清空逻辑、共享网格布局，以及静态设置资源中的中文翻译覆盖。
打包唯一入口为 `./build.sh`。两个包检查元数据、fat 架构、设置入口和面板类、安装卸载脚本及资源 plist。
这些检查不能证明 UIKit 在真实设备上的触摸竞争、远程键盘层级、布局行为。

## 设备验收（iOS 16 / iOS 17，各含冷启动与热启动）

1. 配置左右不同内容，分别从顶部、底部向左/右长滑，确认方向、内容和覆盖范围。
2. 单按钮左右短滑仅执行其绑定动作；点击、长按、上下滑正常；工具栏与空格键不翻页、不清空候选词。
3. 长滑从按钮开始只打开面板，不执行按钮动作；短拖跨按钮、斜向拖动、取消及双指不打开面板。
4. 分别配置左／右／通用的系统控件行、每行图标数、缩放和背景；预览与实际入口使用对应配置，改动一个不会影响其余两个。旧合并开关不再重定向左右入口。
5. 增删、排序、名称、SF Symbol 与 Bundle ID 图标、列数、大小与背景设置立即生效；删空后不恢复默认内容。
6. 关闭按钮、顶部空白/下滑关闭柄、网格空白关闭正常，关闭不落点到键盘；网格纵向滚动不关闭。
7. 操作面板期间输入框保持焦点；关闭面板无键盘收起再弹出的动画；文本动作写入原输入框。
8. 键盘上方 App 区域可操作；切输入框、切 App、收键盘、旋转与设置刷新后无残留窗口或旧动作回调。
9. 单行/双行容量、底部 8 个限制正确；降低列数/关闭双行后超量项关闭，所有记录与手势配置保留。
10. 测试 SpringBoard Spotlight 搜索（包括第三方输入法）、Notes、微信、网页输入框；顶部、候选栏、按键和底部工具栏均被面板覆盖，操作不会穿透至键盘。
11. 面板添加/替换只出现自定义动作；旧基础动作和已删的自定义项不出现，创建系统动作后能加入面板。
12. 首页下拉搜索“面板”，只保留相关条目和分组；清空/返回后列表完整，搜索焦点弹出键盘。面板设置页下拉输入文字可测试实际工具栏和覆盖面板。
13. 修改三套面板的项目、排序、名称图标和外观，预览立即更新，返回父页也更新；空面板显示为空，不生成默认项目。预览可纵向滚动查看更多行。
14. 核对三套面板均有默认五个开关和两条滑条，实际状态与系统一致；操作不关闭面板、不输入文字。快速拖动滑条后系统停在最终值；关闭/重开、切输入框后无旧回复更新新面板。横屏/低高度可滚动访问全部内容。
15. 在左、右、通用配置列表分别左滑删除第一项/中间项/最后一项及删空，确认预览立即变化、退出重进后不恢复；自定义动作和其他面板引用仍在，可再次添加。同名重复项目只删除选中项。“编辑”中拖动排序/红色删除正常，点“完成”后左滑正常。
16. 从三套面板进入“选择动作”：删除已勾选/未勾选/同名不同 selector 项及最后一项；“添加”行不能删除，仍可新建动作，批量“完成”不返回被删项。已有工具栏、子动作和面板引用一并清理；返回/完成/替换后预览更新，不恢复旧引用，替换目标已被删除时不误改其他项目。本选择页不出现拖动排序；其他未开启删除的动作选择页仍为只读。

诊断日志：`[TypeX][KeyboardPanel] open side=… toolbar=… items=…`，包含覆盖 rect、键盘宿主与来源窗口类，以及缺少输入/Scene/几何时的取消日志。不输出输入文本，不写设备日志文件。

## 选择动作页删除分析

问题：面板“选择动作”页只有添加和选择，不能左滑删除。
根因：DXPKeyboardPanelActionPicker 继承的 DXPCustomActionViewController 将可编辑行、
删除样式及 trailing swipe 限制在 customActionsOnly 管理模式；面板 picker 为外部选择模式。
涉及文件：共享选择控制器头文件/实现、面板选择器与添加/替换完成回调、本地化资源。
修改边界：仅面板 picker 显式开启 allowsDeletingCustomActions；其他选择页默认关闭，
管理页继续复用原删除规则，独立管理页排序和已添加面板项目的排序入口保持原状。
实现方案：正常列表左滑展示删除，排除基础动作/添加行；删除定义后复用现有引用清理，
清除选中状态并保存。批量添加与替换从最新偏好重建项目，避免父页缓存恢复已删引用。
不修改的部分：系统执行器、键盘面板窗口、其他插件和已有 DXPLinkActionEditorController.m 修改。
运行时风险：UIKit 手势、列表删除动画、Preferences 生命周期及预览交互需 iOS 16/17 真机验证。
验证步骤：执行既有手势/删除引用及设置布局测试，./build.sh 两目标打包并检查资源/类；
设备按步骤 16 验收，确认删空/勾选删除/完成/返回/替换均不崩溃或恢复已删引用。
