# 可配置面板重构（2026-10-04）

问题：原左／右／通用三个配置槽同时用于键盘与 SpringBoard；工具栏长滑固定打开左右面板，动作目录无法引用新增面板。
根因：配置、设置界面与运行时均以方向作为面板身份，且面板条目只接受自定义动作。
修改边界：面板注册表、动作选择与显示、工具栏／Dock／状态栏的面板路由，以及相关资源与测试。沿用现有键盘宿主、全局窗口、系统控制和打开动作执行器。没有改动其他插件、AI 或剪贴板模块。

## 配置和迁移

- `panels` 保存任意数量的面板，每个包含稳定 `id`、`kind`（`keyboard` / `gesture`）、`name`、`items` 和独立 `preferences`。`icon` 保留为兼容元数据，显示固定使用类型默认图标。
- 面板设置不提供图标输入；键盘面板使用 `keyboard`，手势面板使用 `hand.draw`。条目只允许覆盖名称，图标跟随其动作定义或面板类型。旧面板和条目的图标覆盖不再参与显示；自定义动作定义中的图标仍由原动作编辑页管理。
- `__typex_panel_<id>` 是动作选择值。名称可重复，改名不改变引用。面板条目也能打开同类面板；仅在点击时导航，不递归执行整个动作列表。
- `toolbarpanelbindings` 独立保存 `top.left`、`top.right`、`bottom.left`、`bottom.right`。未配置、清除或失效的动作不触发面板。按钮范围内短滑继续执行按钮自身的手势动作。
- 读取旧面板数据时，每个旧槽复制为一个键盘面板和一个手势面板，确定性的 ID 确保 Settings、App 与 SpringBoard 得到相同结果。已配置的 Dock／状态栏引用改写到对应手势面板，显式清除保持清除。工具栏不迁移隐式左右动作，需要重新选择。
- 新建配置默认没有面板；空／不可用偏好不会因迁移被当成已有配置。首次写入持久化注册表。空注册表作为迁移标记，防止已删除的旧面板重新出现；旧存储键只作为兼容数据保留。
- 删除面板清除工具栏、按钮手势、子动作、Dock、状态栏与其他面板引用。删除面板中的一个条目只移除该引用。删除自定义动作仍保留无关动作定义和面板。

## 触发边界与失败行为

| 入口 | 可选择面板 | 可选择操作 |
| --- | --- | --- |
| 键盘按钮、按钮手势、工具栏长滑 | 键盘面板 | 基础键盘操作及自定义动作 |
| 键盘面板条目 | 键盘面板 | 全部基础与自定义动作 |
| Dock、状态栏手势 | 手势面板 | 现有无需输入框的自定义动作 |
| 手势面板条目 | 手势面板 | 链接、URL Scheme、打开应用、快捷指令、系统动作 |

手势面板可以加入含 `@@@` 的链接。点击时显示“执行失败：手势面板无法读取或替换输入内容，请从键盘面板执行”，保持面板可见，不调用打开执行器、不替换成空字符串、不剪切其他 App 的文字。基础操作、文本和脚本不进入手势候选或条目执行路径。两种面板的 UI 筛选和执行层均校验类型；失效或伪造跨类型引用不执行。

窗口与 Scene 操作保持主线程，键盘会话同时验证原输入对象、原工具栏窗口与偏好快照；配置变更、宿主离开、键盘隐藏或场景失效会关闭面板。没有新增设备日志文件，诊断沿用 syslog。

## 移除面板与条目图标设置（2026-10-04）

问题：面板详情和当前条目外观提供图标设置，而需求只使用默认图标。
根因：面板保存自定义 `icon`，条目也能覆盖引用动作的 `icon`；只删除输入行会使旧覆盖继续显示。
涉及文件：面板注册表、面板设置／动作候选／预览、键盘与全局面板图标渲染、中英文本地化及现有注册表测试。
修改边界：删除两处图标编辑入口；面板图标按类型解析，条目图标从引用定义解析，名称覆盖保留。
实现方案：显示用定义与原始存储定义分开，避免旧图标影响更新／删除定位；条目读取过滤旧图标，保存时不再带回覆盖。
不修改的部分：动作定义的图标编辑、动作执行、手势识别、键盘焦点、Window／Scene 生命周期及其他插件。
运行时风险：真实 Preferences 表单排版与 SF Symbols 渲染仍需 iOS 16／17 设备确认；没有增加私有 API、异步任务或设备日志文件。
验证步骤：本地验证旧配置图标覆盖失效、名称／ID／动作保留、读取不改写原定义、删除目标无显示；运行现有相关 runner，再通过集成后的 `./build.sh` 生成两套包。

设备验收（尚未执行）：iOS 16／17 冷／热启动进入两类面板，确认图标设置行消失；当前条目只编辑名称，列表／预览／实际面板跟随默认图标。使用含旧面板及条目图标覆盖的配置，确认覆盖失效；改名、替换动作、删除条目或面板及再次打开均正常。自定义动作图标经原动作编辑页更改后，面板条目同步显示。检查取消及重复进入编辑不改配置，键盘与面板关闭路径维持原行为。
