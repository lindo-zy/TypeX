# SF 图标选择器多列验收

目标：iOS 16、iOS 17，设置 App 的 TypeX 图标库。以下为设备验收步骤，源码审查和打包通过不能代替设备结果。

1. 冷启动设置 App，从动作编辑器、面板外观分别进入图标库并打开「全部」或任一分类。首次默认四列，搜索框下可切换「单列 / 双列 / 三列 / 四列」。单列显示图标和名称，多列显示图标卡片和两行名称，长名称末尾截断。
2. 向下浏览后依次切换四种列数，原来首个可见图标仍在屏幕上，图标不重叠、不越界。返回分类列表再打开另一分类，本次设置进程内保留列数；退出设置进程后重新默认四列。
3. 输入 `heart`，在搜索结果中切换列数，图标数量和名称保持一致。缩短、清空搜索恢复完整分类；输入无结果名称显示空状态。切换列数不会清空查询或触发选中回调。
4. 搜索键盘弹出时可滚动到最后一项，拖动或按搜索键可收起键盘。横竖屏、深浅色、较大字体下重复切换，图标、名称和已选勾选标记仍可辨认。
5. 从未保存动作与已保存动作分别选择图标，正确回写名称并返回原编辑页；快速重复点击只回写一次。重新进入图标库，已选项有勾选标记；返回分类或退出选择器不改变原图标。
6. 若外部符号 Hook 使缓存图标失效，选择该项应提示不可用、移除该项并保留搜索与列数，返回分类后可重新加载。

只抓 syslog 中 `[TypeX][SFSymbol]`：`layout` 包含分类、列数、当前结果数，`picked` 每次成功选择只出现一次；不在设备写日志文件。
