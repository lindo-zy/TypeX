# Dock 上滑、左滑、右滑

问题：Dock 只有上划开关，动作固定为通用面板，缺少左右滑及单动作选择。
根因：DXDockPanelGestureHandler 只接受向上的 pan，DXPDockGestureController 只有一个开关。
涉及文件：Dock Hook、方向与绑定策略、Dock 设置控制器、自定义动作删除引用、中英文资源和验收文档。
修改边界：只扩展主屏幕 Dock 的三个方向；状态栏与键盘工具栏的识别、面板宿主及系统动作执行器沿用现有实现。
实现方案：三组独立开关与单动作选择，无动作流设置；按起手方向锁定单指 pan，校验配置快照、窗口、Scene、可见性与解锁状态，再执行一次。
不修改的部分：其他插件、旧通知协议、键盘焦点与动作流执行逻辑。
运行时风险：SBDockView 在 iOS 16／17 的实际层级、图标扩大命中区域与桌面翻页／系统边缘手势仲裁需真机验收。
验证步骤：生产方向／配置测试、生产 handler 的 UIKit 替身回调测试、已有 Dock 图像排除／面板／设置／状态栏回归、./build.sh 两套包与实机冷／热启动。

## 配置与行为

设置 → TypeX → 手势设置 → Dock 手势设置，按图显示三组：

| 方向 | 开关 | 动作 |
| --- | --- | --- |
| 上滑 | 启用上滑 | 上滑动作 |
| 左滑 | 启用左滑 | 左滑动作 |
| 右滑 | 启用右滑 | 右滑动作 |

上滑沿用 `keyboardpaneldockswipeBOOL` 和原默认开启状态，未写入动作绑定时仍打开通用面板。左右滑默认关闭、未指定动作。动作可以选择不执行、左／右／通用面板或已保存的全局自定义动作；支持在选择页添加系统动作、应用、快捷操作和 URL Scheme。三组均没有“启用动作流模式”或多动作配置。

显式选择“不执行动作”后不会恢复默认面板；无效绑定／删除的定义不会执行。删除自定义动作会清除相关 Dock 引用并关闭对应开关，其他方向保留。选择动作不会自动改开关。

面板动作受独立面板总开关控制；系统／App／快捷操作／链接不依赖该开关。文本、JavaScript 和含 `@@@` 的链接不能用于 SpringBoard Dock。保留既有全局动作执行能力、确认机制与失败结果，不寻找其他进程的输入框。

起点仍限定可见 Dock 空白、图标之间和下方同宽空白；实际图标图像和控件不接管。主方向位移至少 48pt，且至少为另一个轴的 1.5 倍。方向在开始识别时锁定，反向／斜拖／短拖不能提交。三个方向均在松手时执行；面板在下一轮主队列显示，每次只显示一次，取消不会提交。返回桌面后首次显示的修复与验收见 DOCK_PANEL_FIRST_OPEN.md。

已配置方向对背景 pan 设置动态优先关系，不请求同时识别；系统屏幕边缘 pan 不设该关系。关闭或未指定的方向在开始识别时让出手势。真实系统是否遵循该仲裁须设备验证。

跟踪中配置变化、第二根手指、Dock 移动／离窗、旋转、Scene 失活、App 退前台与切换器转场取消待触发动作。重复安装不累加识别器；离窗和释放清理旧识别器与通知观察。动作结果回调只记录请求 ID、方向、结果和是否仍为当前请求，不更新失效 UI，也不重试动作。新 Dock 来源 `dockgesture` 尊重选定面板，旧 `dock` 来源强制通用面板的行为保留。

## 自动检查与证据边界

- `python3 tests/run-dock-gestures.py`：编译生产策略，并直接抽取生产 Dock handler／安装器，用 UIKit 替身检查取消、单次执行、配置／窗口变化、双指与安装清理。
- `python3 tests/run-global-panels.py`：现有 Dock 起点和实际图标排除策略、三套面板配置与布局。
- `python3 tests/run-settings-ui.py`、`python3 tests/run-statusbar-gestures.py`：现有设置资源／布局及状态栏配置回归。
- 包检查：两个 DEB 元数据、arm64／arm64e、设置入口与翻译、SpringBoard 注入过滤、安装卸载脚本语法。

替身测试不模拟 UIKit 真实触摸仲裁、SpringBoard 私有层级或系统动作实际执行。安装／卸载、冷／热启动和核心功能目前未实机验证。

## 设备验收（iOS 16／17，各含冷启动与热启动）

1. 升级后确认旧上滑开关保持、默认通用面板不变；左右滑默认关闭。三组各两行，不出现动作流设置。
2. 左滑配置左面板、右滑配置右面板，从 Dock 中缝及下方空白起手，松手后打开对应内容；仅启用一个方向时另一方向不执行。
3. 三个方向分别配置系统动作、App、快捷操作或链接，确保每次只执行一次；关闭独立面板后这些动作仍可执行，面板动作不能打开。
4. 选择“不执行动作”，退出重进及冷启动后仍不执行。删除已绑定自定义动作，确认引用清空／开关关闭，其他方向及工具栏、状态栏配置正确。
5. 开关关闭、未指定动作、短于 48pt、斜拖、反向、双指、取消、Dock 外起手和实际图标中心不执行；图标点击、长按、拖动排序及 Dock 外桌面翻页正常。
6. 跟踪中旋转、锁屏、切 App／切换器、设置变化、Dock 更换窗口时不执行旧动作；返回桌面重新触发仍正常，不累加识别器或面板。
7. 失败或系统拒绝时日志记录结果；不重复打开、不写设备日志文件、不输出动作内容或输入文本。

诊断：`[TypeX][DockGesture] installed directions=up,left,right`、`tracking request=… zone=inside/below`、`trigger request=… direction=up/left/right panel=…`、`cancelled request=… state=…`、`result request=… direction=… status=… current=…`；面板对应 `open side=… origin=dockgesture`。
