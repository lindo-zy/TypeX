# 手势设置分类验收

问题：状态栏、Dock 和键盘工具栏的手势配置入口分散。
涉及文件：手势分类控制器、Root.plist、滑动面板设置控制器、中英文资源和入口验收文档。
修改边界：分类入口读取和写入原配置键，保留默认值；Dock 新增三个方向的独立开关与单动作绑定，详见 DOCK_GESTURES.md。状态栏／键盘工具栏识别、动作执行器、面板宿主和跨进程协议沿用现有实现。
方案：设置 → TypeX → 手势设置，提供 Dock 手势设置、状态栏手势、键盘工具栏手势三个分类。
运行时风险：Preferences 的导航、图标显示和开关状态需在 iOS 16／17 实机确认；编译和资源检查不能替代设备验收。

在 iOS 16／17 的冷启动与热启动后分别检查：

1. 先保存 Dock 上划、顶部／底部长滑开关和状态栏动作；升级后进入手势设置，原配置仍显示正确。
2. Dock 分类提供上滑／左滑／右滑三组，每组只有开关和动作；不出现动作流模式。旧上划开关和默认通用面板保留；左右滑默认关闭，可独立绑定动作，完整边界按 DOCK_GESTURES.md 验收。
3. 状态栏分类保留左／中／右各五个独立条目；进入、返回和选择动作正常，每个条目只修改自己的绑定。
4. 键盘工具栏分类仅保留顶部／底部长滑开关及说明；不显示“按钮手势”分组、“顶部按钮手势”“底部按钮手势”入口及其说明。分别切换两个长滑开关，退出重进后状态保持。
5. 滑动面板页不再出现 Dock 上划和工具栏长滑开关；独立面板总开关及左／右／通用面板内容和外观仍可配置。
6. 退出并重新进入设置，三项开关及动作保持；原顶部／底部设置入口仍可配置按钮、布局和外观。

当前设备状态：未装机验证。Dock 诊断日志使用 [TypeX][DockGesture]，不记录动作内容、不写设备日志文件。
